# 国际化系统

## 文件：`src/i18n/`

```
src/i18n/
├── index.ts    # setLocale() + t() 函数
├── en.ts       # 英文翻译
└── zh.ts       # 中文翻译
```

## API

```typescript
type Locale = 'en' | 'zh';

// 设置当前语言
function setLocale(locale: Locale): void;

// 翻译函数
function t(key: string, vars?: Record<string, string>): string;
```

## 使用方式

```typescript
import { t, setLocale } from './i18n';

// 设置语言（在 onload 中调用）
setLocale(this.settings.locale);

// 翻译（带变量插值）
t('notice.renameSuccess', { old: 'old.png', new: 'new.png', notes: '3' });

// 翻译（无变量）
t('command.browseImages');
```

## 翻译键结构

```
command.*          # 命令名称
settings.*         # 设置项名称和描述
notice.*           # 通知消息
ribbon.*           # 功能区图标提示
preview.*          # 预览窗口文本
browser.*          # 浏览器窗口文本
orphan.*           # 孤立图片窗口文本
```

## 变量插值

使用 `{key}` 语法：
```typescript
// en.ts
'notice.renameSuccess': 'Renamed {old} → {new}, updated {notes} note(s)'

// 调用
t('notice.renameSuccess', { old: 'old.png', new: 'new.png', notes: '3' })
// → "Renamed old.png → new.png, updated 3 note(s)"
```

## 翻译覆盖范围

约 180 条翻译键，覆盖：
- 12 个命令名称
- 17+ 个设置项（名称 + 描述）
- 20+ 条通知消息
- 图片浏览器、预览、孤立检测的 UI 文本
- 图床配置表单的字段标签
- 远程浏览器的本地/图床标签、范围、空前缀确认、分页、引用索引状态和 unsupported 提示
- S3 远程列表的配置、认证、权限、Bucket 不存在、限流、网络、XML 解析和服务错误提示
- S3 手动预览的访问方式、加载、失败、重试、请求计数、公开 URL 缺失、非图片与归档对象提示
- 七牛云区域名称

## 新增翻译步骤

1. 在 `i18n/en.ts` 添加英文键值对
2. 在 `i18n/zh.ts` 添加中文键值对
3. 在代码中使用 `t('key')` 或 `t('key', { var: value })`

## 注意事项

1. **Sentence case**：英文 UI 文本使用 sentence case（首字母大写，其余小写）
2. **品牌名保持原样**：如 "Aliyun OSS"、"S3" 等
3. **技术术语小写**：如 "access key ID"、"bucket" 等
4. **变量名一致**：中英文翻译中的变量名必须一致
