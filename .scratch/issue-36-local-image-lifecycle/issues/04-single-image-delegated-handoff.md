# 04 — 打通单图 delegated 自动图床接力

**What to build:** 让 delegated 用户粘贴或拖放一张图片时，由 Obsidian 或其他附件管理者完成本地处理，Image Manager 在文件和事务精确引用达到可接力状态后上传，并只替换本次事务产生的引用。

**Blocked by:** 03 — 拆分本地压缩与上传载荷压缩授权。

**Status:** ready-for-agent

- [ ] delegated 不阻止 Markdown 编辑器的 paste/drop，也不创建、命名、移动或修改本地附件。
- [ ] 单图事务绑定来源笔记，建立输入图片、最终 `TFile` 身份和新增引用的唯一映射。
- [ ] Markdown 与 Wiki 本地引用均使用 Obsidian 链接解析语义验证，不按 basename 猜测。
- [ ] 观察到文件变化后引用跟随时形成强收敛并使用 200ms 缓冲；只有唯一初始映射时形成弱收敛并使用 800ms 缓冲。
- [ ] paste/drop 后 30 秒硬超时不可延长；超时保留本地文件和引用并提示显式上传。
- [ ] 事务快照默认图床、上传压缩、引用模板和本地副本策略；图床不可用时取消且不改投其他目标。
- [ ] 上传前、上传后和替换前重验事务指纹；成功时只替换事务精确引用。
- [ ] 用户删除目标引用时静默取消；歧义或失败时失败关闭并按事务汇总一次。
- [ ] 首个端到端切片固定保留本地文件，不在本票启用自动回收。
- [ ] 确定性假时钟测试覆盖强/弱收敛、超时、Wiki/Markdown、精确替换和图床快照。
- [ ] canonical 架构、本地工作流、图床、设置与领域语言文档同步为“部分实施”。
- [ ] `npm test`、`npm run build` 和 `git diff --check` 通过。
