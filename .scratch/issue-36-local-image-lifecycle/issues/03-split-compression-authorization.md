# 03 — 拆分本地压缩与上传载荷压缩授权

**What to build:** 让用户分别控制 managed 粘贴时对本地附件的压缩，以及自动、手动、笔记和批量上传时对上传载荷的压缩；delegated 永远不因自动上传修改外部管理者创建的本地文件。

**Blocked by:** 02 — 交付本地管理权选择与完整退出路径。

**Status:** ready-for-agent

- [ ] 提供 managed 本地粘贴压缩与上传载荷压缩两个独立设置，并共享压缩质量。
- [ ] delegated 下本地粘贴压缩不可用，但上传载荷压缩仍可配置。
- [ ] 手动当前图片、笔记图片、批量和自动上传只压缩内存载荷，不修改 Vault 原文件。
- [ ] 显式“压缩当前图片”继续作为覆盖本地文件的独立命令，不受两个自动设置控制。
- [ ] 旧 `autoCompress` 同时迁移到两个新设置，使现有 managed 有效行为保持不变。
- [ ] managed 自动上传在本地结果已按相同质量压缩时直接使用该结果，不进行重复有损压缩。
- [ ] 本票不改变或诊断现有编码格式与文件扩展名策略。
- [ ] 设置 UI、迁移、managed/delegated 行为以及所有上传入口的测试通过。
- [ ] canonical 本地工作流、图床、设置与领域语言文档同步。
- [ ] `npm test`、`npm run build` 和 `git diff --check` 通过。
