# 07 — 保护状态未定图片与安全本地回收

**What to build:** 确保 delegated 事务中或刚经历外部变化的本地图片不会被瞬时误判为孤立；自动上传成功后，也只有在精确引用替换并证明全库无本地引用时才允许回收本地文件。

**Blocked by:** 05 — 支持连续操作、多图与上传竞态的失败关闭。

**Status:** ready-for-agent

- [ ] 活跃委托事务涉及的图片在本地浏览器和孤立图片窗口中显示为状态未定，不可选择删除。
- [ ] 事务结束或最后一次相关 move/rename/reference 变化后，对受影响图片保留两秒逐图保护；相关变化重启该图片保护。
- [ ] 两秒保护不阻塞其他图片或整个扫描，使用可注入时钟进行确定性测试。
- [ ] 浏览展示、删除确认前和实际执行前都重新验证引用与近期变更状态。
- [ ] `keepLocalCopy=false` 只在事务精确引用替换并重验成功后启动全 Vault 本地引用扫描。
- [ ] 存在其他本地引用、扫描失败、状态歧义、事务变化或文件消失时均保留或跳过本地文件。
- [ ] 只有仍存在、无本地引用、保护已结束且事务指纹有效的图片通过回收站删除。
- [ ] 自动接力不扩大替换到事务之外的同文件引用；这些引用会阻止本地回收。
- [ ] 删除和跳过结果按现有安全汇总语义报告，不暴露敏感远端信息。
- [ ] 测试覆盖活跃、近期变化、保护到期、确认竞态、执行竞态、其他引用和回收失败。
- [ ] canonical 本地工作流、孤立管理设计、设置/UI 与领域语言文档同步。
- [ ] `npm test`、`npm run build` 和 `git diff --check` 通过。
