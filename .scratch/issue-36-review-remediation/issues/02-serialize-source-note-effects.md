# 02 — 建立来源笔记的安全读取与串行写入边界

**What to build:** 事务始终绑定原来源笔记；原 Editor 仍可验证时使用其当前内容，Editor 关闭后仅在 Vault 保存内容能唯一恢复目标时继续；同一来源笔记的重定位、替换和本地回收串行执行。

**Blocked by:** 01 — 证明委托事务项的附件与引用归属

**Status:** completed

- [x] 切换活动笔记不会把事务迁移到新笔记，也不会忽略仍存在且可验证的来源 Editor 未保存内容。
- [x] 来源 Editor 已关闭或无法证明仍绑定来源笔记时，只在 Vault 内容可唯一恢复事务引用时继续，否则取消并保留本地状态。
- [x] 同一笔记两个上传同时完成时，引用替换、重新定位和回收按顺序执行，不发生重叠写入或基于过期内容的覆盖。
- [x] 不同来源笔记仍可独立并行，上传并发上限保持两项。
