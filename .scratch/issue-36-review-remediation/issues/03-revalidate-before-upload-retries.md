# 03 — 每次上传尝试前重新验证事务

**What to build:** delegated 上传的首次请求和每次网络重试前都重新验证附件、精确引用、来源内容与配置快照；事务已变化时停止后续尝试，不采用已失效结果。

**Blocked by:** 02 — 建立来源笔记的安全读取与串行写入边界

**Status:** completed

- [x] 首次上传和每次重试前均通过同一事务有效性检查，检查失败后不再发出新的网络请求。
- [x] 请求在途期间发生相关变化时允许该请求结束，但结果不替换引用、不回收本地文件，也不按新状态自动上传。
- [x] 上传服务的普通手动、笔记和批量重试行为保持不变，事务校验只由需要该能力的调用方显式提供。
- [x] 测试覆盖首次请求前失效、首次失败后重试前失效及成功结果返回前失效。
