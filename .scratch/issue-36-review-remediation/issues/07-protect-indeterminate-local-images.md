# 07 — 保护活跃及近期变化图片的未定状态

**What to build:** delegated 活跃事务和近期 move、rename、引用变化涉及的图片在逐图保护期内属于状态未定，不能显示、选择或删除为孤立；保护结束后恢复现有的新鲜扫描与双重复扫流程。

**Blocked by:** 01 — 证明委托事务项的附件与引用归属；06 — 批处理并串行化外部 rename 修复

**Status:** completed

- [x] 活跃事务中的图片在图片浏览器、孤立图片窗口、确认前复扫和执行前复扫中均不会获得孤立删除资格。
- [x] 事务结束或最后相关变化后按图片保留两秒保护；同一图片的新相关变化会重启其保护期，不影响其他图片扫描。
- [x] 保护期内界面表达为状态未定且不可选择，保护结束后重新依据最新 Vault 状态分类。
- [x] 假时钟测试覆盖活跃、两秒边界、保护重启、确认和执行时变化，以及插件卸载后的清理。
