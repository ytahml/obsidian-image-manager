## 产品契约

- 命令面板中，“Wiki 图片转 Markdown”和“上传笔记引用的图片”各只提供一个范围入口；进入后默认全库，并允许选择递归文件夹或单篇 Markdown 笔记。
- 笔记与文件夹右键菜单使用被点击目标，而不是活动笔记。上传打开配置弹窗并预选目标范围；Wiki 图片转换直接执行对应笔记或递归文件夹范围，不再二次确认。
- 单张图片上传仍是独立命令，不与按笔记范围上传合并。
- 不注册已收束的重复命令 ID；已有快捷键需要由用户重新绑定到保留的统一入口。用户文案不展示“兼容快捷入口”等实现历史。

## 安全边界

- 范围由 Markdown 笔记定义；文件夹范围包含子文件夹，但不能匹配相邻同名前缀。
- Wiki 图片转换读取打开 Editor 的实时内容；多个 Editor 内容分歧、文件身份或内容变化、读写失败均保留原文。单篇失败不阻断其他独立笔记，不承诺跨文件原子事务。
- 转换只处理可安全解析的 Wiki 图片引用，不移动或删除图片，不触发网络请求，也不受上传或粘贴格式设置限制。
- 上传继续遵守按笔记范围上传契约：只上传范围笔记引用的本地图片，引用替换是本次操作选项；本地副本按当前模式设置保留，关闭保留时也仅在成功替换与 fresh 安全检查通过后移入回收站。
