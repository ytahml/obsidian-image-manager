# 本地图片引用安全

## 目标

本地孤立图片检测采用 fail-closed 策略：只有完整扫描中不存在可靠引用、也不存在无法唯一解析的候选时，图片才可被选择或移入 Obsidian 回收站。

## 边界

- 只读引用索引覆盖 Markdown、Wiki、HTML、frontmatter、Canvas 与 Excalidraw 的可解析图片使用；它不定义格式转换、上传替换、重命名或整理的可写范围。
- 图片身份以真实 Vault `TFile.path` 表示。解析优先使用 Obsidian 公共链接语义；歧义短链接保护全部候选，绝不按文件名猜一个目标。
- 无法判定、未保存编辑器内容或生命周期保护都没有删除资格。确认前及每次实际回收前均须重扫，并只能调用 `fileManager.trashFile()`。
- 外部 URL、Vault 外路径、动态脚本与未解析的第三方数据不证明本地图片无引用。

## 验收

引用扫描、预览定位、手动清理和自动回收共享同一安全判定；可靠引用、歧义和 unknown 均不得误删图片。
