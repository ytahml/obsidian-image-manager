# 按笔记范围上传图片

> 状态：本地副本策略修订已实现并通过自动验证，尚未完成本次真实 Obsidian/provider 验收；合并与发布不替代真实验收。当前实现以 canonical skill references 与代码为准。

## 产品契约

- 全库、递归文件夹、文章范围用于选择 Markdown 笔记，上传这些笔记可唯一解析的受支持本地图片；附件目录不限制图片选择，不上传孤立文件。
- 同一源文件在一次操作中仅上传一次。保留文件身份、完整路径及内容版本，不从服务商结果文件名推断源文件。
- 引用替换为本次操作可选项，默认取全局偏好，但不反写全局设置。开启时更新全库 Markdown 中指向成功图片的引用，包括范围外笔记；确认界面必须说明此影响。
- 手动单图和范围上传共用当前受管/委托模式的“保留本地副本”设置，与粘贴自动上传是否开启无关。操作开始时冻结模式和保留偏好；回收前重新校验，设置变化则保留。
- 关闭保留时，仅上传成功、源身份/版本有效、至少一处引用成功替换且本次引用写回无冲突/失败的图片可进入回收候选。未开启替换、零替换、失败或未采用的结果保留本地文件。
- 候选须经两次 fresh 全库引用扫描，保护 Markdown/Canvas、未保存 Editor、歧义引用和生命周期未定状态；扫描期间文件集/版本或 Editor 绑定/内容变化时保留。仅调用 `fileManager.trashFile()`，不永久删除或清理目录。
- 上传、引用更新、本地回收分别报告；回收失败不改变已成功上传的事实。不存在跨文件原子事务，不自动回滚或删除远端对象。
- 打开的 Markdown 使用实时 Editor；未打开笔记使用受快照校验保护的 Vault 写回。文件身份/版本变化或多个 Editor 内容分歧时失败关闭。
- 范围上传只保留 `batch-upload` 统一入口，命令默认全库，文章/文件夹右键预选目标范围；重复的 `upload-note-images` 不再注册。未实现占位命令不注册，不把未实现能力作为可用功能展示。

## 验收边界

自动测试覆盖范围、去重、身份、并发冲突和分阶段结果。真实 Obsidian/provider 验收与自动验证分别记录；未完成真实验收时不声明兼容性或上线完成。
