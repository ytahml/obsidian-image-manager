# 当前设计契约

本目录只保存跨模块、难以从代码直接推导的当前产品决策。实现细节放在 `.agents/skills/obsidian-image-manager/references/`，用户说明放在 README，发布变化放在 CHANGELOG。

## 当前状态

本项目当前没有需要默认加载的设计草案。已完成设计保留在本目录并标记为“归档”；后续开发先读取 references，只有需求改变既有产品边界时才按需打开对应归档设计：

- [本地图片生命周期](issue-36-local-image-workflow-ownership.md)
- [远程对象管理](issue-17-remote-image-management.md)

## 维护规则

1. 文件按产品能力命名，不使用 Issue、PR 或内部阶段编号。
2. 只记录当前仍生效的目标、决策、安全边界和验收边界，不维护实施流水或完成清单。
3. 新功能在设计期可有临时计划；实现稳定后把持久决策合入对应主题文档并标记归档，移除临时计划。
4. 已归档内容不进入默认 task route。需要追溯时使用 [文档归档登记](../archive/README.md) 或 Git 历史。
5. 小修复和可直接从代码、类型、配置或测试读出的事实不重复写入设计文档。
6. 行为变化必须同步对应 reference 与设计契约；验收结论只描述实际覆盖范围。

新增主题只有在现有两份契约无法自然容纳、且决策会长期影响多个模块时才新建文件。
