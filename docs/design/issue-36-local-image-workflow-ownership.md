# 本地图片生命周期

> 状态：归档
>
> 本设计对应的实现已完成。当前实现事实以 `.agents/skills/obsidian-image-manager/references/` 为准；除非修改本地图片产品边界，否则不需要读取本文。

本文定义新本地图片从 paste/drop、附件创建和引用插入，到可选图床接力、引用替换、重命名、整理和孤立清理的长期产品边界。

## 管理权与自动上传

- `managed`：本插件接管 Markdown 编辑器 paste/drop，负责创建、命名、路径、本地压缩和初始引用。
- `delegated`：Obsidian 或外部附件管理者负责本地处理；本插件不阻止默认事件，也不创建、移动、重命名或修改附件内容。
- `autoUploadOnPaste` 与本地管理权正交。`delegated` 且关闭自动上传时不建立事务。
- 本地管理模式只约束自动 paste/drop；手动上传、浏览、重命名、整理和压缩命令仍可用。
- `managedPasteReferenceFormat` 只控制 managed 初始引用；`reorganizeConvertFormat` 只控制显式整理转换。两者都不门控图床能力。

## Delegated 接力契约

接力只依赖 Obsidian 公开事件、Editor 内容、Vault 状态和链接解析，不依赖第三方插件 ID、私有队列或固定完成延迟。

- 每次 paste/drop 是一个内存事务，绑定来源笔记；一次事务可有多个独立图片项。
- 每项必须证明输入、最终 `TFile` 和本次新增完整引用的一一映射；重复或歧义项失败关闭。
- Markdown 目标先按路径段容错解码，再使用 Obsidian linkpath 语义解析；事务身份保留原始完整引用。
- 来源 Editor 仍可验证时读取其最新内容；Editor 关闭后，只有 Vault 内容能唯一恢复目标时才继续。
- 事务快照图床、上传压缩、上传路径、引用模板和本地副本策略。相关设置变化会使结果失效，不改投其他图床。
- 每次网络尝试前、请求返回后、写回前和本地回收前重新验证。失效的成功结果不替换引用、不删除本地或远端对象。
- 自动接力只替换事务精确引用，不扩展到同文件的其他引用；每个事务最多一条汇总通知。
- 最多两项并发上传；同一来源笔记的重定位、替换和回收串行执行。
- 事务不跨插件卸载恢复。主动删除目标引用导致的取消保持静默。

强收敛表示已观察到附件 move/rename 后引用跟随并唯一解析；弱收敛表示初始附件与引用已唯一映射但没有后续变化证据。内部缓冲分别为 200ms 和 800ms，事务硬超时 30 秒；这些不是用户设置，也不代表第三方处理“最终完成”。

## 压缩与本地副本

- managed 本地粘贴压缩与上传载荷压缩是独立授权，共享质量设置。
- delegated 不修改外部管理者创建的本地附件；需要压缩时只处理上传载荷。
- `keepLocalCopy=false` 不是删除授权。只有精确远端引用已写入、事务仍有效且 fresh 全 Vault 扫描确认没有本地引用时，才可回收附件。
- delegated 自动回收先释放活动保护，再等待完整两秒逐图保护期；期间相关变化取消回收。

## 引用、浏览与安全清理

- 用户命令只公开 Wiki 图片到 Markdown 的转换；Markdown 到 Wiki 不属于当前用户能力。
- Markdown 路径逐段编码语法敏感 ASCII，保留 Unicode 和 `/`；解析已有本地引用时逐段容错解码。
- 本地浏览器显示已引用、孤立和无法判断。活动 delegated 事务及最后相关变化后两秒内的图片属于状态未定，不可选择为孤立。
- 孤立清理在展示后不缓存资格：确认前复扫、执行前再复扫，只对仍存在且仍孤立的 `TFile` 调用 `fileManager.trashFile()`。
- 本地孤立清理不永久删除文件，也不清理父目录。自动上传成功后的空直接附件目录清理是独立、非递归且失败不改变上传结果。
- 自定义上传引用模板必须包含 `{fileUrl}`；未知变量或不可用的请求尺寸使该次引用回退标准 Markdown，不改变上传成功状态。

## 重命名与整理

- 内置重命名先更新引用再执行 `vault.rename()`，避免宿主链接更新丢失目录信息。
- 外部 rename 链合并为首个旧路径到最终新路径的批次；批次之间不重叠，delegated 状态未定期间延后。
- 断链修复依据 Obsidian 链接语义和路径上下文；多个候选都能解释同一引用时不猜测。
- 整理跳过远程 URL，按路径基准重新计算引用；格式转换只受 `reorganizeConvertFormat` 控制。

## 平台与验收边界

- 自动接力面向 Markdown 编辑器；Canvas 不在自动接力范围内，仍可使用显式上传。
- 桌面环境已验证 Image Manager 单独运行、与 Attachment Management 0.12.1 协作、连续事务、多图、上传压缩以及 rename/孤立保护。
- Attachment Management 0.12.1 会在重命名后继续写回本地引用；当前只声明 `delegated + keepLocalCopy=false` 兼容，`keepLocalCopy=true` 不声明支持。
- 移动端、Canvas 自动接力、所有语法与事件组合及其他附件插件没有完整真实矩阵，不得宣称通用兼容。
